## 데이터와 분석 연결

- 기존 `users/{uid}/diaries`, `users/{uid}/events`, `analyzeDiary` callable을 사용합니다. 데이터베이스 규칙·인증·저장 경로는 변경하지 않았습니다.
- 사용자 감정 `기쁨`·`신남`은 읽을 때 `행복`으로 호환합니다. 과거 사용자가 입력한 `평온함` 기록은 보존하고 새로운 감정으로 임의 변환하지 않습니다. 해당 값은 현재 5감정 비율·흐름·돌봄에서 제외되지만 일기 수·만족도·원문에는 남습니다. 과거 일기의 달력 아이콘은 기존 `calm.png`로 보존했습니다.
- AI 사건에 44개 원점수가 있으면 공식 44→5 매핑으로 다시 계산하여 표시합니다. 원점수·DB 문서는 덮어쓰지 않습니다. 서버의 새 결과도 동일한 5감정 매핑을 사용하도록 `backend/src/analyze.ts`를 수정했습니다.
- 기존 사건 추출 버전 `v2`는 유지합니다. 감정 매핑 수정 때문에 전체 일기를 유료 모델로 다시 추출하지 않습니다. 기존 결과의 표시 보정은 저장된 원점수에서 처리합니다.
- 수정 전 원문 버전, 삭제된 일기, 현재 본문에 없는 근거는 AI 집계에서 제외합니다. `sourceContentVersion`, `analyzedContentVersion`, `analyzedPipeline`을 확인합니다.
- AI 진입 시 선택 기간의 미분석 일기만 최대 2편씩 요청합니다. 실패를 자동 반복하지 않고 재시도 버튼을 제공합니다. 처리 중 다른 기간을 열면 마지막 요청 기간을 이어서 처리합니다.
- 기본 통계는 사용자 감정, AI 주제별 감정 비율은 부여된 사건 감정에서 계산합니다. 없는 만족도는 0으로 바꾸지 않습니다.
- 기존 안내와 HTML의 ‘1회 무료·이후 월간 구독’ 문구는 유지했습니다. 이번 변경은 실제 결제·사용 횟수 차감·구독 차단 기능을 추가하지 않습니다.
- 기존 요약/반복 상황 규칙은 유지합니다. 자주 나온 단어는 `garu-ko@0.9.18`의 한국어 형태소 분석으로 일반명사(NNG)·고유명사(NNP)만 추출합니다. `잠` 같은 한 글자 명사를 포함하고, 대명사·조사·서술어·시간 관련 불용어를 제외합니다. 형태소 분석에도 오분류 가능성은 있습니다.

- 마음 돌봄 문구는 16px 굵은 글씨로, 날짜는 다음 줄의 12px `MM/DD ~ MM/DD`로 표시합니다. 실제 연도를 포함한 날짜는 `time` 요소에 유지합니다.
- 워드클라우드는 흰 배경에 빈도별 크기의 주황색 계열 단어를 겹치지 않게 배치합니다. 클릭·키보드 선택 시 해당 단어가 나온 기간 내 일기만 보여줍니다.

- 행복 주제 막대는 주황색 `#f2a044`입니다.
- 보고서·돌봄·원문 대화상자에 고운돋움과 진한 갈색 본문을 적용합니다. 글꼴은 `@fontsource/gowun-dodum@5.3.0`으로 자체 호스팅합니다.
- 라이선스/출처: [Garu(MIT)](https://github.com/ongjin/garu), [고운돋움(SIL OFL 1.1)](https://github.com/yangheeryu/Gowun-Dodum). 새 의존성은 정확한 버전과 lockfile로 고정했습니다.
